# おでかけリール（インスタ）

- 毎日 08:50 に .github/workflows/ig-post-reel.yml が ig/reels/<日付>.json と media/reels/<日付>.mp4 を投稿する。
- 作り方: `python3 tools/outing_reel/make.py ig/reels/<日付>.json media/reels/<日付>.mp4`
- 決まり（2026-10-28 オーナー）
  - 曲は 10/31〜 オーナーのフリー音源のピアノ（tools/brand/reel_bgm.m4a、make.py が動画に入れる）。spec の audio_id は空 ""（10/30 オーナー「明日からのリールも今のピアノのやつ。とても合ってた」）。前は「金木犀とオレンジの空」（audio_id 1638443601035185）。
  - 表紙の上は2行「関西の不動産屋が」（小・橙）／「街の調査で見つけた、おでかけリスト」（太・橙）、2行とも同じ橙（10/28 16:32 決定）。キャプションの1行目は必ず「関西の不動産屋が、街の調査で見つけたおでかけリスト」（10/28 14:19 オーナー決定）。
  - 動画を作り直したら必ず新しいファイル名にして spec の video_url を書く（Pages のキャッシュ対策）。
  - 事実は公式ページで確かめる。府県は順番に。
  - キャプションの形：1行目（上の決まり）・空き行・題・✦ の行・✧（※は使わない）・◎ 公式ページはプロフィールのリンクから・「保存して、週末のおでかけに。」・その次の行に TOWN NOTE の紹介を1行・ハッシュタグ。
  - TOWN NOTE の紹介の1行（11/2 オーナー「インスタにもHPの紹介を」）：次の6つを順番に使い、同じ日に朝と夕方で同じ行を使わない。HPに無い機能は書かない。
    1. 関西のおでかけを、日付と地図つきでまとめた「TOWN NOTE」。プロフィールのリンクから見られます。
    2. 今いる場所から間に合うおでかけは、TOWN NOTE の「いまから行ける」で。プロフィールのリンクから。
    3. 遠い会場の近くの宿も、TOWN NOTE の「泊まり」にまとめています。プロフィールのリンクから。
    4. 関西のイルミネーションも、府県ごとに TOWN NOTE にまとめています。プロフィールのリンクから。（12/31 まで）
    5. TOWN NOTE は、ホーム画面に追加するとアプリのように使えます。プロフィールのリンクから。
    6. 街ごとの地価や人口は、TOWN NOTE の「関西不動産リスト」に。プロフィールのリンクから。
  - 週に1本は「TOWN NOTE のご紹介」リール（ig/reels/oneoff/、HPの画面を見せる29秒）を夕方の枠と入れ替えて出す。
