- 毎日 08:50 に .github/workflows/ig-post-reel.yml が ig/reels/<日付>.json と media/reels/<日付>.mp4 を投稿する。
- 作り方（11/11〜 新しい型。オーナー OK「縦書き・線画・声は4か所だけ・落ち着いた大人の女性の声」）：
  **夜の回は spec（ig/reels/<名前>.json）を main に入れるだけ。動画は .github/workflows/outing-reel.yml が声つきで作って media/reels/ に置く**（手元では作らない。手元には声の機械が無い）。
  - spec に足す欄：
    - `"voice"`: 声の台本を4行（①始まり「〜で、〜が始まります。」②日付「11月13日から、29日まで。」③見どころを1つ ④「ほかの〜は、プロフィールのリンクからどうぞ。」）。1行は25字くらいまで、です・ます、急がない短い文。場所と料金は読まない（画面で見せる）。読み間違えやすい名前はひらがなで書く。
    - `"video_url"`: `https://oreusa.github.io/usagi-fudosan-media/media/reels/<名前>-v1.mp4`（作り直す時は -v2 と名前を変える。機械は「そのファイルがまだ無い spec」だけ作る）。
    - `text.motif`（任意）: 見どころの下の線画。`tahoto`（多宝塔）・`tou13` や `tou5`（重ねた塔。数字は層の数）・書かなければ月。
    - `text.fall`（任意）: `leaf` で葉が落ちる。書かなければ、文に もみじ・紅葉 がある時だけ落ちる。
    - キャプションのハッシュタグの前の行に `声：VOICEVOX:もち子(cv 明日葉よもぎ)` を1行（声の決まり）。
  - 縦書きに入る長さ：point_title は8字くらいまで、points は1行14字まで、date_title は8字くらいまで。info は4行のうち「17時〜21時」の形の行が大きく出る。
  - 確かめ方：入れて数分後に Actions の outing-reel が緑か、media/reels/ に動画があるか。失敗の時は記録に「声の読み」と理由が出る。
  - 見た目だけ手元で見る：`python3 tools/outing_reel/make.py ig/reels/<名前>.json /tmp/x.mp4 8,14,20`（静止画）。
  - 関西・関東で make.py は同じ物。違い（表紙の2行・さし色・地図・曲）は region.py だけ。前の型は make_old.py。
