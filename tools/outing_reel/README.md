# おでかけリール（インスタ）

## 絵本の型（11/12〜 これが今の型。オーナー「リールは絵本を開く型」）
**夜の回は spec（関西 ig/reels/<名前>.json・関東 akari reel/<日付>.json）を main に入れるだけ。機械が声を作り、読みを答え合わせし、動画にして置く。**
spec に書く物（前の型の欄に足す）：
- `"kata": "ehon"`（これがあると絵本の型で作る。関東はさらに `"brand": "kanto"`）
- `"voice"`: 声の台本を **6行**。①場所の話「奈良の山の上に、〜があります。」②季節「秋になると、〜。」③いつまで「〜は、12月6日まで。」④夜・見どころ「14日からは、夜のあかりもともります。」⑤料金や行き方 ⑥「ほかのおでかけも、日付と地図からさがせます。プロフィールのリンクからどうぞ。」
- `"voice_yomi"`: 上の6行の **正しい読みを、行ごとに全部ひらがなで**（数字もひらがな。「12月6日」→「じゅうにがつむいか」）。機械が実際の声の読みとくらべ、1文字でも違えば動画を作らずに止まる。
  止まったら：その言葉を voice の中でひらがなに直す → tools/outing_reel/yomi.json の fix に「間違えた書き方 → 正しく読む書き方」を1行足す（次から自動で直る。消さない）。
- `text.ehon1`・`ehon2`・`ehon4`: 絵のページの縦書き（3行ずつ。1行8字くらいまで）。1＝場所、2＝季節、4＝夜。
- `text.ehon_night`: 夜のページの数字 `["11.14", "SAT", "から", "日没〜20時半"]`
- `text.motif`: 絵。`tou13`・`tou5`（重ねた塔。数字は層）／`tahoto`（多宝塔）／`shrine`（神社と鳥居）／`temple`（お堂）／`yama`（建物なし）
- `text.seal`（判子の2文字。書かなければ「紅葉」）、`text.peaks: 1`（遠くに2つの峰の山）、`text.ehon5`（最後のページの3行）
- 前の型と同じ：`text.title`・`corner`・`place`・`date`・`date_title`・`info`（4行まで）・`info_note`、`video_url`（作り直す時は名前を変える）
確かめ方：入れて約15分後に Actions の outing-reel が緑か。赤の時は記録の最後に理由（読みの違い・足りない欄）が出る。
見た目だけ手元で見る：`WORK=/tmp/w python3 tools/outing_reel/ehon.py <spec> /tmp/x.mp4 "1.5,5,9.5,14.5,19,23"`（静止画）。
出す時の落とし穴：動画を main に入れてから GitHub Pages に出るまで約1分半かかる。その前にインスタへ渡すと失敗する（11/12 エラー 2207076）。
