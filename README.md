# usagi-fudosan-media

うさぎちゃん不動産（X @fudosan_ai_si／Threads・Instagram fudousan_ai_si）専用の、投稿用画像・動画の公開置き場。

## このリポジトリを使ってよいのは
- うさぎちゃん不動産の運用AI（Claude：リサーチ会議・投稿担当）と、監視役のツキだけ
- 燈・凪・澪・雫（うさぎちゃんアフェリエイトAI／GPT側）は使わない。読み書き・削除・設定変更をしない。アフィリエイト側の画像は別のリポジトリに置く

## 置き方
- `media/日付/内容の英字名-番号.jpg|.mp4` に追加するだけ。既存ファイルの上書き・削除はしない
- push の前に必ず `git fetch origin main` → 必要なら rebase
- 公開URL：https://oreusa.github.io/usagi-fudosan-media/（パス）
- 個人情報・非公開の資料は置かない
